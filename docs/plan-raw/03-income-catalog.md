# CATEGORY B — WORTH THE EXTRA 10-15HR/WEEK IF YOU PURSUE THEM
## Genuinely new skill required. Ranked by value-per-hour-invested.

### 1. Docker + basic AWS/cloud (highest recommendation in this category)
**Extra time cost:** ~20-30 hours total to reach baseline competence, then ongoing freelance use
**Why this is the best use of extra hours:** containers and cloud basics directly reinforce
what you're already learning conceptually in Y2 (OS processes, isolation, resource limits —
a container is essentially a lightweight OS-level virtualization concept). This isn't a
detour, it's applied systems knowledge.
**Income unlocked:** basic DevOps/SRE-adjacent freelance gigs (server setup, CI/CD pipelines,
basic deployment automation) — real, common on Upwork, $25-60/hr
**When to do it:** Y2 Q3-Q4, right after xv6 kernel work, while OS concepts are fresh
**Resource:** Docker's official "Get Started" guide (free) + AWS Free Tier hands-on practice

### 2. FastAPI/Flask web framework basics
**Extra time cost:** ~10-15 hours to reach working competence
**Why it's worth it:** you already know Python deeply and you already know requests/APIs
from Y1 Q2 — this is the missing other half (building APIs, not just consuming them)
**Income unlocked:** "build me a backend API" freelance gigs, more sellable than scripts alone
**When to do it:** Y1 Q4 or Y2 Q1, right after your GraphKit API work — natural extension
**Resource:** FastAPI's official tutorial (free, excellent, fast to complete)

### 3. Selenium/Playwright (browser automation)
**Extra time cost:** ~8-12 hours
**Why moderate, not high, value:** narrow skill, lower ceiling than the above two
**Income unlocked:** web scraping/RPA freelance gigs that BeautifulSoup can't handle
(JavaScript-heavy sites) — real demand but a smaller niche
**When to do it:** only if you specifically encounter a freelance gig that needs it —
don't pre-invest, learn it just-in-time

### What I would NOT spend the extra 10-15hr/week on

**A full course/ebook product** — the production time cost is high (40-80+ hours to make
something genuinely sellable) and the market is uncertain for a first-time creator with
no existing audience. Revisit this in Y3-Y4 once you have real visibility (blog readers,
GitHub followers) — the same effort then has a much higher expected return.

**Building a "bot-as-a-service" business** — already addressed: not viable until Y3-Y4
skill-wise, and the framing needs to be legitimate client services, not anything
ambiguous about platform terms of service.

**Discord/Telegram bot freelance gigs** — real micro-market exists on Fiverr, but the
income ceiling is low ($20-50 per bot, one-off) relative to the time cost of marketing
yourself for it. Not worth dedicated hours; pick up only if you stumble into a specific gig.
